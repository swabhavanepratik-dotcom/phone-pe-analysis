# 📱 PhonePe Analysis Dashboard | Power BI

## 📌 Project Overview

The **PhonePe Analysis Dashboard** is a data analytics project developed using Microsoft Power BI to analyze PhonePe transaction data and user activity. The dashboard presents key performance indicators (KPIs) and interactive visualizations to help understand transaction performance, user trends, and success rates.

The main objective of this project is to transform raw data into meaningful insights through data cleaning, data modeling, and interactive dashboard development.

## 🎯 Project Objectives

- Analyze transaction performance and transaction value.
- Monitor total users and user activity.
- Track transaction success rates.
- Identify trends over different time periods.
- Present key business insights through interactive visualizations.
- Practice data analytics and dashboard development using Power BI.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard creation and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – Calculated measures and KPIs
- **Data Modeling** – Organizing tables and relationships
- **Date Table** – Time-based analysis using year, month, and quarter

## 📊 Key Performance Indicators (KPIs)

The dashboard focuses on important metrics such as:

- **Total Transaction Value** – Overall value of transactions.
- **Total Transactions** – Total number of transactions recorded.
- **Total Users** – Number of users represented in the dataset.
- **Success Rate** – Percentage of successful transactions, based on the available status data.
- **Time-Based Trends** – Analysis of performance across different dates and periods.

## ✨ Dashboard Features

- Interactive dashboard with visual reports.
- KPI cards for quick performance monitoring.
- Date-based filtering for exploring different periods.
- Visual analysis of transaction and user-related data.
- Clear and user-friendly dashboard design.
- Data transformation and calculated measures for meaningful analysis.

## 🔍 Business Value

This project demonstrates how Power BI can be used to convert raw transaction data into an interactive analytical report. It helps users explore key metrics, recognize trends, and understand transaction performance more efficiently.

## 📚 Skills Demonstrated

- Data Cleaning and Transformation
- Data Modeling
- DAX Measures
- KPI Development
- Data Visualization
- Interactive Dashboard Design
- Business Data Analysis

## 🚀 How to Use This Project

1. Download or clone this repository.
2. Open the `.pbit` template file using Microsoft Power BI Desktop.
3. If prompted, connect to the source dataset and update the data source path.
4. Refresh the data and verify that the required tables and measures load correctly.
5. Explore the dashboard using its available filters and visualizations.

**Note:** The Power BI template may require the original Excel dataset or an updated source path to load the data successfully.
